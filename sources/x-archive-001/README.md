## 原本と索引

登録簿は [x_sources.json](../../data/x_sources.json)、索引は [x_posts.jsonl](../../data/x_posts.jsonl)、件数と進捗は [x_manifest.json](../../data/x_manifest.json) です。索引は投稿日時順で、IDは `x-archive-001:<投稿ID>`。本文ハッシュ、投稿URL、返信先、entities、編集情報、ZIP内のレコード位置を保持します。原本の全フィールドはZIP内に残ります。

再生成は `python3 tools/build_x_index.py`。ZIPとメンバーのハッシュを照合し、変更・重複があれば生成前に拒否します。追加の期間が重複するアーカイブは、黙って別事例にせず、重複の整理を必要とします。
