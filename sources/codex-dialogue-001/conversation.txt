User
一問一答形式だと話しやすいかも。
色んなことどんどん聞いてみて。

Assistant
頑張っているけれど、やり方を変えないと上達しそうにない人がいたら、あなたはどう声をかけますか？

User
僕はそんなに親切じゃないんだ。わざわざ教えたりはしないけど、自分のやり方とは違うことだけは告げるよ。その人の実力が自分より上かもしれないし。

Assistant
自分より実力が下だと分かっている相手でも、教えてほしいと言われなければ、やり方の違いを伝えるくらいに留めますか？

User
そうです。求めよ、さらば与えられん。です。

Assistant
では、「教えてほしい」と頼まれたら、どんな相手には時間を使って教えたいと思いますか？

User
頼まれればどんな相手であっても与える事はしますね。それこそ寸借詐欺だろうなぁ、と分かっていても与えたりしますね。見返りはないと分かっていても「タバコを一本くれ」と言われれば呉れてやるし。もちろん教えを乞われれば時間を割くのは吝かでない。

Assistant
頼まれたときでも、「そこまでは応じられない」と断るのは、どんな場合ですか？

User
責任を取れないとき。不可逆的な場合。端的に言うとそう。

Assistant
相手が「結果は自分で引き受ける」と言っても、あなたには責任を取れないと感じる場合、断りますか？

User
それを明言されたら協力はしますね。

Assistant
相手が「自分で引き受ける」と言っても、そのリスクを十分に理解していないように見えたら、どうしますか？

User
その場合は、リスクについて僕が知っている範囲で話すよ。

よく、光回線の乗り換え案内みたいな電話がかかってくるんだけどさ。
安くなりますよとか言って工事費が掛かりませんよとか言って乗り換えを勧めてくるじゃん？それについて、僕は決まってこう答えるんです。
「お好きにどうぞ」と。
それで何を思ったかひとしきり質問をしてくるから答えるわけね。それでその後、別の契約チームから電話掛かってくるの。そこで毎回終わり。
なぜかと言うと、彼らは「僕が乗り換えをしたい」という意思をちゃんと確認しないで次のチームに引き継いじゃうから。
僕は最初から「安くしてくれ、速くしてくれ」って頼んでるわけじゃなくて、好きにしていいよとしか言ってないわけよ。
で、契約チームと話が合わないのはそこを確認してないからなのね。
毎回そういう話になると分かってても、毎回話を聞き、好きにしていいよと言い、別チームから「契約しますか？」って質問に「いいえ」と答えざるを得ない。

Assistant
「お好きにどうぞ」と言うとき、あなたとしては具体的に、相手が何をしてよいと伝えているつもりですか？

User
回線を速くします、安くします。っていうから素晴らしいですね、好きにして良いですよ。って言ってるつもりです。この段で契約を交わす必要があるってことを言う人がいないのですよ。

Assistant
最初から「安くするには新しい契約が必要です。その条件を説明してもよいですか？」と聞かれたら、どう答えますか？

User
契約には何が必要ですか？って尋ねると思います。
それなら、おそらく書類を送るのでハンコを押してくださいって話になると思うので、「じゃあ嫌です、面倒くさいです」って言えるんですけど。

Assistant
書類や押印が不要で、その電話だけで手続きが済むとしても、契約条件を確認したうえで断ることはありますか？

User
電話だけで済むなら契約条件を確認して、承認したり拒否したり判断しますよ。

Assistant
自分から頼んでいなかったけれど、誰かにしてもらって嬉しかったことはありますか？

User
僕と関わってくれること全てについて感謝しているよ。何かをくれたりしなくても、話しかけてくれるだけで嬉しいよ

Assistant
誰かと話していて、「この人ともう少し話したい」と感じるのは、どんなときですか？

User
するべきことが他になければ、誰かと話をすることに抵抗はないね。もちろん僕から好意を持っている人ならなおさらだけど。

Assistant
人に好意を持つきっかけになるのは、その人のどんなところですか？

User
僕にはない長所を見つけたときかな。そしてそれは大抵の人間にある。僕が他人の完全上位互換ではないので。

Assistant
最近、「この人のここは、自分にはない長所だな」と感じた具体的な場面はありますか？

User
僕には「ただ歩く」ってことが好きって感覚はよく分からないんだけど、それが好きだという男に会ったよ。どれくらい歩くか聞いたら想像以上に距離を歩くことができるそうでビックリした。

Assistant
その人に惹かれたのは、長い距離を歩けることと、自分には分からない楽しみを知っていることの、どちらが大きかったですか？

User
後者かなー。聞いたあとでも自分も歩いてみようとは思わなかったけど。それが楽しめるってすごいなと思って。

Assistant
人が楽しんでいることに対して、「それはやめた方がいい」と口を出したくなるのは、どんなときですか？

User
楽しんでいる人の陰に泣いている人がいるような事かな

Assistant
楽しんでいる本人が、その陰で誰かが泣いていることに気づいていなさそうなら、どう伝えますか？

User
本人に教えるほど親切じゃないし、泣いている人に手を差し伸べるほども親切ではないのだよね。

Assistant
それでも、実際に口を出したり、止めに入ったりするのは、どんな場合ですか？

User
それを続けると、怪我や命の危険があるときには口を出すだろうね

Assistant
危険を負うのが楽しんでいる本人だけなのか、周りの別の人なのかで、あなたの対応は変わりますか？

User
それは変わりますね。本人が危険を負うことについてはかなり寛容です。周りの人に危険があることについては、指摘します。

Assistant
周りへの危険を指摘しても、相手が「大丈夫だ」と取り合わず続けたら、どうしますか？

User
ふーん、大丈夫なのか。　と納得したり、それでも危険なのであれば当人よりは周りの人に指摘するよ

Assistant
相手の「大丈夫」で納得できる場合と、それでも危険だと思う場合は、何を手掛かりに見分けますか？

User
一意で決まるところじゃないな。その人との関係性で変わってくると思う。

Assistant
同じことを「大丈夫」と言われても、信じやすい相手と信じにくい相手では、どんな違いがありますか？

User
さっきの、ふーん大丈夫なんだ、は信じているというより説得を諦めてるに近いよ。信じてなくて危ないよ〜って思ってる

Assistant
危険だとは思ったまま、説得を打ち切るということですね。信じたと読み違えました。

周りの人にも危険を伝え、その人たちが「承知の上です」と言ったら、そこで任せますか？

User
そうですね、見ている人も納得づくなら誰が怪我しても仕方ないんじゃないでしょうか。

Assistant
子どもなど、その危険を十分に理解して判断できない人がいる場合は、どうしますか？

User
危険の程度による。命に関わるような事は阻止しますけど、そうでないなら怪我するのも経験値のうちでしょう。

Assistant
「経験値になる」と見守れる怪我と、止めるべき危険は、どんな点で線を引きますか？

User
重度の後遺症が残るかどうかかな。骨折れる程度は治るしやってみたら良いんじゃないかなぁなんて思いますよ。

Assistant
自分が保護者や引率者として安全を任されている相手でも、その線引きは同じですか？

User
その場合は若干安全に振れますね。無事に帰すまでが保護者、引率者の責務と考えます。

Assistant
逆に、自分が誰かに助けを求める側になることには、抵抗がありますか？

User
全然ありません。が、自分で色々出来るので頼らなくても出来ることが多いほうであります。瞬間瞬間で手が足りないとかそういう場合に誰かに頼ることに抵抗はありませんね

Assistant
誰かに作業を任せたとき、自分とは違うやり方で進めていたら、どこまで口を出しますか？

User
全然気にしません。が、成果が検証不可能な方法だったら、検証時に指摘します。

Assistant
成果を検証できないとき、相手には具体的に何をしてもらいますか？

User
次回に検証が可能な状態で試行するようお願いするだけですね。成果は成果として成立するかだけを見ます。手戻りして検証可能な方法で差し戻しはしません。

Assistant

User
自分が作成した（したであろう）成果と同一かどうか、かな。

Assistant
自分の想定とは違う成果が出てきた場合は、どう扱いますか？

User
作業目標と照らして、その成果が十分であるかどうかを、検証します。目的を達するのに足りれば良し、足りなければそれは差し戻し。

Assistant
目的を十分に満たしていても、「自分の美意識に合わない」という理由で直してもらうことはありますか？

User
それはありません。合わないなーと思っていても、目的を達するなら気にしません。（気にはしてるかも。でも別にいいやって感じ）

Assistant
自分で作るときも、目的を満たしたら「美しくないけど、これでいい」と区切れますか？

User
自分で作るものについては自分の美意識を満足する事が完成条件に入ります。

Assistant
自分の美意識と、依頼主が望む仕上がりが食い違ったら、どうしますか？

User
自分の美意識がまず優先で成果を作成。依頼主の美意識に足りない場合は依頼主の美意識に合わせて再作成を厭いません。自分には美意識は働くけれども最優先ではなくてよい

Assistant
納品したあとで、自分の作ったものが誰かの好みに合わせて手直しされていたら、どう感じますか？

User
ここで怒れるのがアーティストなのでしょう。僕は成果物について矜持を持って作成はするものの、その後の利用法について言及する権利がないと考えているのでどうされててもあんまり感慨はありませんね。さすがに貰い捨てみたいにされるとちょっと悲しく思ったりはするだろうけども。

Assistant

User
美意識分の仕事が不要だった否定を感じるからでしょうか。その後はクオリティを下げて納品するでしょう。

Assistant
その場合、次の納品では具体的に、どの部分のクオリティを下げますか？

User
必要十分を満たすのみで足りるか反応を見ます。

Assistant
必要十分に絞ったあと、相手から「前のような仕上がりにしてほしい」と言われたら、どう応じますか？

User
貰い捨てにされるのは、自分の感想であって、必要な条件だったのだと解釈してクオリティを戻します。

Assistant

自己満足ですね。　さきほどの経過を辿った後に元に戻すように言われたなら、その時始めて認められたように思うかも。

Assistant
言葉で褒められることと、実際にその仕事を必要とされることでは、認められた感覚に違いがありますか？

User
わざわざ言葉にして褒めてもらえると嬉しいよね。

次の依頼があるって事は成果が足りていたから、次も依頼があるということだと捉えます。それも嬉しいことだよね。

端的に成果の良い部分を褒めます、あんまり途中経過の努力を褒めることはしないかも。
