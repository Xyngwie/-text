# Codexとの一問一答（抜粋）

このチャットの「一問一答形式だと話しやすいかも」から、今夜の会話をまとめてmainへ組み込む指示までを、質問と回答を省かず手動転記した範囲抜粋です。サービスの全履歴エクスポートではありません。元妻とのゲームについての説明など、この範囲以前の会話は含みません。

`conversation.txt` の独立した行の `User` / `Assistant` が話者境界です。質問はCodexの文であり、本人の自発的な主張として扱いません。引用された営業電話なども本人の回想内の報告として区別します。モデルの厳密な名称・各発言の日時は元データに明記されていないため補っていません。

登録後は本文を上書きせず、新しい会話は別原本へ追加します。登録簿は `data/sources.json`、分類は既存の会話用索引・レビューへ、原本ID `codex-dialogue-001` を付けて追加します。質問の誘導や途中の訂正を含めて参照し、同じ対話の連続回答を独立した再現例として数えません。
