# 短編を X 投稿用に整える

作品ファイルの「## 投稿用」ブロックは、そのまま貼れる素の形です。X に投稿するときは、本人が次の形に整えています。このスキルは、その書き方をまとめたものです。本文の言葉は変えません。変えるのは、改行と空行と字下げ、それに元記事URLだけです。

## なぜこの形か

X では、長い投稿の冒頭だけが表示され、残りは「つづきを読む」に折りたたまれます。本人の言う「280字くらい」は X の数え方で、全角1字を2と数えます。全角ならおよそ140字です。空行が入ると、表示される範囲がそこで短くなります。そのため、冒頭は空行を入れずに一つの大きなかたまりにして、読み始めの量を確保します。

## 整え方

1. **題名は『』で囲み、改行せずに本文の1文目へつなげる。** 例：`『いつもより』給食センターで、毎朝米を炊く。`
2. **冒頭のかたまり。** 本文の最初の段落から、空行を入れずに続ける。段落の切れ目は空行ではなく改行1つにする。長さは X の数え方で280以内（全角でおよそ140字以内）に収め、文の途中では切らない。
3. **字下げを消す。** 行頭の全角スペース（　）は全部取る。
4. **冒頭のあとは、一文か二文ごとに空行を1つ入れる。** 意味のつながりで区切る。続けて読ませたい二文は同じ行に置くか、改行1つでつなげて同じかたまりにする。
5. **セリフは独立させる。** 「」のセリフは前後に空行を入れて一つのかたまりにする。長いセリフも途中で空行を入れず、一つのかたまりのまま改行する。
6. **短い一文で決める行は、それだけで一行にする。** 例：「少しだけ減らした。少しだけ、だ。」「おれの水加減のせいではない。たぶん。」
7. **免責と元記事は最後に、空行を1つ挟んで2行で置く。** 免責の一文は作品のとおり。元記事URLは、Google News のリンク（`news.google.com/rss/articles/...`）ではなく元の記事の直接URLにする。
   - Google News のリンクは curl では元記事へ転送されない（JavaScript で転送するため）。見出しと配信元で Web 検索し、配信元のサイトにある同じ見出しの記事のURLを使う。
   - 見出しが一致する記事が見つからないときは、推測で URL を作らない。Google News のリンクのまま渡し、「直接URLは見つからなかった」と一言添える。
8. **数える。** 冒頭のかたまり（題名から最初の空行まで）の長さを X の数え方で数え、報告に一言添える（例：「冒頭は全角133字、Xの数え方で265」）。

数え方の目安（全角を2、半角と改行を1とする）:

```bash
python3 -c "import sys; s=sys.stdin.read().rstrip('\n'); print(len(s), sum(2 if ord(c)>0x10FF else 1 for c in s))" <<'EOF'
<冒頭のかたまり>
EOF
```

## 渡し方

- 整えたものは ```text ブロックに入れて返答に載せる。作品ファイルの「## 投稿用」は書き換えない。
- 投稿はしない。ボタンは本人が押す。

## 例（2026-11-11「いつもより」、本人が実際に投稿した形）

```text
『いつもより』給食センターで、毎朝米を炊く。中学校と小学校、あわせて何百食ぶん。釜の前に立って十二年になる。
米を炊くのに、腕の差はあまり出ない。水の量と時間を決めたら、あとは機械がやる。家でそう言ったら、「じゃあ誰でもいいじゃない」と言われた。そのとおりだと思う。

その日の献立表には、「新米」と小さく書いてあった。村でとれた米だ。

午前中に学校で米の授業があって、昼にそれを食べる段取りらしい。

いつもと同じ時間で炊いた。新米は水を少し減らすものだと言う人もいる。

少しだけ減らした。少しだけ、だ。

午後、食缶を回収しに学校へ行った。返ってきた食缶の重さで、残りがだいたいわかる。その日は軽かった。

配膳室で、当番の生徒が二人、食缶を運んできた。一人が言った。

「今日のごはん、いつもよりおいしかったです」

おれは、ああ、と言った。それしか出なかった。

帰りの車で考えた。いつもより、というのは、何と比べているのか。

きのうの米か。先週の米か。おれが炊いた、ほかの日の米か。

米が新しかったからだ、と思う。

授業で米の話を聞いたからでもあるだろう。自分の村の米だと思って食べたら、それはうまいだろう。

おれの水加減のせいではない。たぶん。

それでも、その一言はなかなか頭から出ていかなかった。
十二年、「おいしかった」は何度か聞いた。「いつもより」は初めてだった。

いつもより、と言うには、いつもを知っていないといけない。

あの子は、毎日食べていたのだ。黙って。

次の日も、同じように米を炊いた。水は、きのうと同じだけ減らした。

食缶は、きのうほど軽くはなかった。

まあ、そんなものだ、と思った。

それでも、明日もこの水の量でやってみるつもりでいる。
```
