# 分析方法と限界（v012）

v012はコミット `5a3d1e6d0e6c35ca6fd69f7659e2efb9ddfc8b4e` に固定し、v011の164場面・452本人発言、19項目の仮説を変更せず引き継ぎます。新しい証拠事例は追加していません。

モード校正では、AIへの委任に関する一つの立場、理由、反論への限定、結論を先に固定し、それを通常・ギャル・お嬢様の三案へ変換しました。これにより、価値判断の差を口調の差として誤認しないようにしています。各案の最後には同一の武将調の一文を置き、本文との落差だけを比較できるようにしました。

作例は本人の新しい発言でも、過去発言の引用でもありません。通常案の構文には原本で反復を確認したものを使いましたが、ギャル案・お嬢様案にはモードを成立させるための候補語も含まれます。候補語を本人の確定語彙へ昇格させるには、本人の評価または今後追加される原本中の実例が必要です。

原本はCopilotとの会話一つです。別LLM比較、未見ニュースに対する生成テスト、完全なモード遷移例の頻度測定はまだ行っていません。
