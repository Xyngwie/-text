# 初版からの変更（v001 → v002）

初版の方向性への肯定と継続の指示を受け、分析プールから25場面を追加しました。累計は58場面・142の本人発言です。今回の目的は、仮説に合う例だけを増やすことではなく、条件を狭めたり、別の説明を必要にしたりする例を探すことでした。

## 判断仮説の修正

| 項目 | 初版から加えたこと | 主な追加事例 |
|---|---|---|
| J01：責任の範囲 | 代理発信についての関心を追加。ただし指示の送り先を取り違えた例を残し、責任への敏感さを手順の正確さとは分けた。 | E35、E36、E43、E45、E49 |
| J02：費用と得たいもの | ゲームでは長時間を嫌うだけでなく、課金による短縮にも異論がある。過程の楽しさ、作る満足、共有の支出を追加。 | E47、E50、E55、E58 |
| J03：説明の量 | 終了には、十分な成果ができた場合だけでなく、まだ構想を溜めておく保留もある。 | E38、E41 |
| J04：任せる範囲 | AIの能力を試した結果で役割を変える例と、自分で作品紹介の骨子を書く例を追加。 | E34、E41 |
| J05：説明への問い返し | 試行や実際の経緯でAIへ反例を出す例を追加。一方、メディアへの反応には伝聞からの強い疑いもあり、一般的な慎重さへ広げない。 | E34、E42、E52、E56 |
| J06：意味と使いやすさ | 自分には便利でも他者には不便かもしれないUIと、送付状の経緯に合う接続を追加。 | E34、E42 |
| J07：強い言葉の後 | 表現を限定しても、注意を続ける意志が残る。仕事を終える発言も、気持ちの整理が済んだとは限らない。 | E45、E46、E56 |
| J08：相手との距離 | 個別調整だけでなく、複数の相手へ同じトーンを使う判断がある。直接の相手の事情や周囲への伝わり方を含む仮説へ変更。 | E48、E52、E53、E57 |
| J09：商売の価値（新規） | 商売が生む価値と、その仕事を真っ当と信じる人の善悪を別の問いとして扱う。今は限られた材料からの仮説。 | E37、E39、E40 |

各事例の原文は [根拠ページ](cases.md) にあります。J09を追加しても、善人・悪人の分類や、営業の違法性の認定を行ったわけではありません。

## 口調の修正

作品の引用はAI相手だけでなく、職場で通じたという自己報告もあります。ただし、相手が作品を知っていることが条件です。冗談をどこでも使う特徴へは広げません。

終了の言葉には「十分できた」「まだ溜めておく」「苛立ってやる気がなくなった」があります。区切りがあるだけで、問題が解決した、納得した、という意味にはしません。

今回も引用や短い否定を数えた頻度分析ではなく、文脈の中での使い方を読んでいます。

## 変えていないこと

- v001の成果物、原本、第二段階の分類は変更していません。
- 分析プール522区間、再利用保留45区間の割り当ては引き継いでいます。
- 保留分は過去の分類ですでに読まれており、未見テストとは扱いません。
- 政治的立場、診断、投資や賭け方の有効性は推定していません。
- ユーザーによる「良い感じ」は、初版の方向性への肯定として記録しました。すべての仮説の正しさが確認された、とは記録していません。

第三段階全体は分析継続中です。次は分析プールの未コーディング区間から、各仮説の条件をさらに比べます。
