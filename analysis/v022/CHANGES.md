# 第二十一版からの変更（v021 → v022）

- [公平を、同じ結果ではなく反撃可能性で見る](fairness_and_counterplay.md)を追加しました。
- 共通の入口、正解した行動への報酬、購入・反復回数によらない成果、設計を越える発見を分けました。
- 同じ規則でも立場や技能で効果が異なる例を残し、形式的な平等だけで公平と判定しないようにしました。
- RSS生成に、誰が同じ規則へ入れるか、正当な攻略法が残るか、結果差が何に由来するかを検討する規則を加えました。

ポーカーとゲームの例が多いため、今回は探索的な価値観候補です。正式な事例、仮説、根拠数は据え置きです。v001〜v021の内容も変更していません。
