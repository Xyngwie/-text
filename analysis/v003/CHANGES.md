# 第二版からの変更（v002 → v003）

第二版を凍結したまま、分析プールから25場面を追加しました。累計は83場面・214の本人発言です。今回は、既存仮説に合う場面だけでなく、説明を止める理由、批判対象の置き直し、構想と実績の差を優先して選びました。

## 主な更新

| 項目 | 第三版で加えた条件 | 主な追加事例 |
|---|---|---|
| J01：責任と確認 | 裁量内では進める一方、未決事項、第三者への負担、公開承認は確認点になる。 | E66、E70、E75、E80 |
| J02：効率以外の価値 | 観察と言語化、経験、社会への役立ち、市場成功と別の創作価値を追加。 | E64、E76、E78、E79、E81 |
| J03：説明の区切り | 満足だけでなく、誤り回避や本来の目的へ戻す終了を追加。 | E65、E77、E80 |
| J04：委任と承認 | 周知の集約と、生成後・公開前の承認点を追加。 | E60、E66、E70 |
| J05：問い直し | 現場を見る前に批判先を決めない意図と、両側を演じる整理法を追加。 | E65、E67、E77 |
| J06：使える表現 | 手順の再開点、観察を言葉へ分解する例を追加。 | E64、E76 |
| J07：強い表現の限定 | 言い訳と弁明、人と行為を分ける言い直しを追加。 | E63、E80、E83 |
| J08：関係全体 | 観衆への発信、仲介者が負う借り、模擬的な反論を追加。 | E65、E68、E75 |
| J09：価値と善悪 | 製品と販売構造、合法性と実質価値、市場成功と創作価値を分けた。 | E71、E72、E73、E81 |
| J10：段階化（新規） | まず扱える形を作る場合と、開始前に継続性を調べる場合の条件を仮説化。 | E59、E62、E74、E78、E82 |

## 変えていないこと

- v001とv002、原本、第二段階の分類、分析プールと再利用保留の割り当ては変更していません。
- 同じ開発・列・商売の会話は、事例数が複数でも独立した人数や独立検証として数えていません。
- 構想は実行済みの行動、本人の評価は外部事実、自己説明は診断として扱っていません。
- 既存ログは遡及的に読まれているため、保留分は未見検証ではありません。

第三段階は継続中です。次は未コーディング区間から、10仮説に当てはまらない場面と、今回まだ薄い感情の切り替わりを探します。
