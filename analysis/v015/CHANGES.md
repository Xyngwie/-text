# 第十四版からの変更（v014 → v015）

新しい会話事例や人物仮説は追加していません。本人の提案に基づき、本人修整後の実投稿を次回の生成精度へ戻す校正ループを設計し、記録・検証ツールを実装しました。

- AI初稿、本人修整、本人承諾、実投稿を別イベントとして保存します。
- 本人修整とプラットフォーム側の自動変換を区別します。
- 承諾後の修整は承諾を無効にし、再承諾なしの投稿記録を拒否します。
- 承諾本文と送信本文のハッシュ一致を検査します。
- 修整を事実、強度、口調、構文、論点へ分け、戻す分析先を定義しました。
- 単発修整を恒久的な本人らしさへせず、複数の独立投稿で反復を確認します。
- 実装手順と機密情報を保存しない規則を追加しました。

v001〜v014の内容は変更していません。
