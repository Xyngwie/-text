# 第十三版からの変更（v013 → v014）

新しい事例や人物仮説は追加していません。本人の指定に基づき、公開投稿案の既定強度と、外部発信を実行するための承認条件を確定しました。

- 公開投稿・発言案の既定強度を2.25にしました。
- 強度2.25を、強度2の構造を保ち末尾の損失評価だけ一段強める値として定義しました。
- AIによる下書き生成と、本人名義での外部実行を分離しました。
- 最終文面、公開先、実行時点、添付物への本人承諾を自動投稿の必須条件にしました。
- 承諾後に内容や公開条件が変わった場合は、再承諾が必要としました。
- 承諾文面と送信文面の照合、実行結果の報告、承諾記録の項目を定義しました。

v001〜v013の内容は変更していません。
