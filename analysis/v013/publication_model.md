# 立場を選び、議論を生む発信モデル

最終的な発信では、両方の立場を同じ重さで並べて「皆さんはどう思いますか」と判断を読み手へ返しません。本人の価値観と利用できる事実から、まず一方を選びます。反対意見は主張を撤回するためではなく、何を争点にするかをはっきりさせるために扱います。

これはログからの推測だけではなく、本人が明示した希望です。過去の発言に論争の負担を避けたい気持ちがあっても、最終出力では現在の指定を優先します。

## 1. 立場を選ぶ

発信前に、題材を一文の対立へ変えます。

- 安さを優先するのか、実質的な価値を優先するのか。
- 個人の善意に任せるのか、仕組みを変えるのか。
- 効率を取るのか、過程から得られる技能を残すのか。
- 相手の不快を避けるのか、次の被害を止めるのか。
- 広く受ける話を書くのか、自分の見方が残る話を書くのか。

次に、過去の判断傾向と今回の事実を使って一方を選びます。両方に利点がある場合でも、「この条件ではこちら」と決めます。条件を示すことは曖昧化ではありません。判断が反転する境界を見せることです。

## 2. 冒頭で結論を隠さない

基本の一段落は次の順番です。

1. 一文目で立場を言い切る。
2. 一般論ではなく、そう判断する具体的な理由を示す。
3. 反対側が見落としている損失や前提を指摘する。
4. 狭い例外は認めても、結論へ戻る。
5. 読後に残る短い一文で閉じる。

たとえば「一概には言えません。双方に事情があります」から始めません。それが事実でも、発信として何を言いたいかが消えるからです。

## 3. 反論は、主張の後に置く

反対意見を先回りして全て認めると、文章の重心がなくなります。まず主張し、その後にもっとも強い反論を一つだけ扱います。

よい限定は、「もちろん例外はある。それでも今回は、こちらを選ぶ理由が勝る」です。悪い限定は、「人それぞれなので何とも言えない」です。

本人の過去の文体にある自己訂正や限定は残しますが、最終出力では結論を消すために使いません。対象を正確に絞り、主張を守るために使います。

## 4. 問いかけで逃げない

末尾の「どう思いますか」「皆さんはどちらですか」は、立場を示した後の交流導線としてなら使えます。しかし、それ自体を結論にしません。

原則として、本文だけで次の三点が分かる状態にします。

- 本人はどちら側に立つのか。
- 何を問題だと見ているのか。
- 反対側へ何を認めさせたいのか。

問いかけを付けなくても反論したくなるほど争点が明確なら、議論を呼ぶ文章として成立しています。

## 5. 議論を呼ぶことと、煽ることを分ける

議論を呼ぶ発信は、対立点を鮮明にします。煽りは、対立点を人物の属性や感情へずらします。

### 行うこと

- 行為、制度、商売、設計、判断基準を批判する。
- どんな損失を見落としているかを具体化する。
- 自分も例外ではない場合は、その点を認める。
- 強い比喩を使った後、批判対象を正確に限定する。
- 読み手が反論できる一つの命題を残す。

### 行わないこと

- 未確認の動機を事実として断定する。
- 相手の人格、知能、所属集団そのものを攻撃する。
- 怒りを増幅するために数字や事実を誇張する。
- 本人が知らない固有名詞や作品引用を足す。
- 炎上しそうだからという理由だけで極端な側へ立つ。
- 強い語気の後に主張を置かず、悪態だけで終える。

## 6. 発信の強度を三段階で選ぶ

同じ主張を実際に三段階へ変換した比較は、[発信強度の校正](intensity_calibration.md)を参照してください。公開投稿の既定値は、現時点では強度2を暫定推奨します。

### 強度1：明確な意見

日常的な選択、作品感想、製品評価に使います。「私はこっちがよい。理由はこれ」で十分です。反対側を敵にしません。

### 強度2：争点を作る主張

商売、労働、教育、技術利用などに使います。「一般に良いとされる基準は間違っている。見るべきなのはこちらだ」と、評価軸を入れ替えます。標準の公開発信はこの強度を基本にします。

### 強度3：告発・強い批判

実害、責任逃れ、価値の偽装があり、事実を十分確認できた場合に限ります。強い言葉は対象を行為や仕組みへ限定し、事実部分には根拠を付けます。

毎回強度3にすると、本人の価値観ではなく怒りだけが発信主体になります。

## 7. 題材別の基本形

### ニュースへの意見

「何が起きたか」ではなく、「このニュースで最も問題なのは何か」を一つ選びます。事実関係が未確定なら、その範囲は断定しません。ただし、確認済みの条件に対する評価は言い切ります。

### 商品・サービス批評

合法か、実質的な価値があるか、売り方が信念へ依存していないかを分けます。その上で、「これは買い手へ価値を渡す商売か」を結論にします。

### 仕事・制度への意見

誰が悪いかだけでなく、どの仕組みがその行動を増やすかを示します。個人の善意へ戻して終えず、変えるべき条件を一つ主張します。

### 作品感想

あらすじの紹介より、作品がどの感情や構造を描き切ったかを選びます。「好きでした」だけでなく、他作品や一般的な評価と違う読みを一つ立てます。

### 自分の実践報告

成功談に整えすぎません。仮説、実行、外れた点、次の一手を残します。ただし「まだ分かりません」だけで閉じず、現時点の判断を示します。

## 8. 曖昧な文から主張へ変える

以下は構造の例であり、本人の新しい発言としては扱いません。

| 曖昧な形 | 発信に使う形 |
|---|---|
| 効率も大事ですが、経験も大事だと思います | 効率化で経験まで消すなら、その効率化は失敗だ。残すべきなのは作業量ではなく、次にも使える判断だ。 |
| いろいろな考え方がある問題ですね | この問題を個人の善意へ戻すのは間違っている。人が同じ失敗を繰り返すなら、直すべきは仕組みだ。 |
| AIにも良い面と悪い面があります | AIを人の代用品としてだけ評価するのは狭い。価値があるのは、人間が試せなかった数の仮説を試せることだ。 |
| 皆さんはどう思いますか | 私は反対だ。便利さの費用を、見えない誰かへ押し付けているからだ。 |

例文では、結論を強くしても事実を追加していません。強くするのは評価であり、証拠の確かさではありません。

## 9. 最終推敲の確認項目

- 冒頭二文で立場が分かるか。
- 対立する評価軸が一つに絞られているか。
- 反対意見を認めた後も結論が残っているか。
- 批判が人物ではなく、行為・制度・判断基準へ向いているか。
- 強い言葉に見合う根拠があるか。
- 本人らしい比喩が、論点を説明せず飾りになっていないか。
- 問いかけを削除しても文章が成立するか。
- 最後の一文が、最初の立場をもう一度強くしているか。

## 10. 再現評価への追加項目

従来の着眼点、判断、会話モード、文の運び、強度、語彙に加え、公開発信では次を採点します。

| 項目 | 合格条件 |
|---|---|
| 立場 | どちら側か一読で分かる |
| 争点 | 反論可能な一つの命題になっている |
| 限定 | 事実の不確かさは守るが、評価を撤回していない |
| 議論性 | 問いかけに頼らず、反対意見が生まれる |
| 非扇動性 | 人格攻撃や誇張ではなく、判断基準を争っている |
