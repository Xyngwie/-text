# 第十二版からの変更（v012 → v013）

新しい事例や人物仮説は追加していません。v012の三モード作例に対する本人評価を記録し、口調モードとは別に、同一主張の「抑制・標準・強め」を校正しました。

- 通常・ギャル・お嬢様の三案と武将調への復帰が、いずれも本人の書きそうな口調だとの確認を記録しました。
- お嬢様モードの方向性を、本人申告のみの暫定案から作例確認済みへ更新しました。
- 効率化への同じ主張を三強度で書き分けました。
- 強度を、結論の位置、評価語、限定、終わり方の四つへ分解しました。
- 公開発信の既定値として「標準 ★」を暫定推奨しました。
- 強め案でも人物攻撃や未確認事実の誇張を行わない境界を明示しました。

v001〜v012の内容は変更していません。
