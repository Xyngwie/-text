# ギャル・お嬢様・武将のモード遷移

本人の説明によれば、ギャル語やお嬢様言葉は単発の装飾ではありません。一度使い始めると「モード」に入り、その文章中は調子を維持し、最後だけ急に元の武将のような言い回しへ戻ることが多いとのことです。

これは原本だけから推測した頻度傾向ではなく、本人が直接示した再現規則です。

## 基本状態

通常状態は、現代口語を中心に、短い訂正、条件の追加、俗語、技術語、作品比喩が混ざる話し方です。通常状態にも「である」「〜なのだが」のような少し古い書き言葉が入りますが、それだけでは完全な武将モードとは扱いません。

## ギャルモード

驚き、他人の内心の演技、軽い自虐、流行語そのものを笑う場面で入りやすいモードです。

モードへ入った後は、単語だけでなく次を揃えます。

- 評価を大きく、即時的にする。
- 語尾を軽くし、親しい距離へ寄せる。
- 「マジ」「めっちゃ」「〜み」のような語を、同じ区間の調子として扱う。
- 古い流行語を使う場合は、古さへの自己認識もオチにできる。

同じ段落の途中で急に無色の解説文へ戻さないことが重要です。

## お嬢様モード

丁寧さを実務的に上げるのではなく、身分、気品、誇張された余裕を演じて面白がるモードです。業務敬語とは別に扱います。

- 語尾だけでなく、評価や要求まで婉曲で大げさにする。
- 一度始めたら、段落内では通常口語へ細かく往復しない。
- 実在の相手へ送る業務文には、自動的に転用しない。
- 本人の実例がないお嬢様語を、辞書から大量に補わない。

「ありがとう存じます」のような作品由来の貴族語遊びは近い例ですが、お嬢様モードと完全に同一とはまだ断定しません。

## 武将・古風モード

本人の通常口調の奥にある帰還先です。長い武士演技を常時続けるというより、評価、決意、諦観、総括を一段高い物語へ持ち上げます。

- 「解せぬ」で不満を判決のように閉じる。
- 「仕官」「あやつ」「ワシ」で人物関係を物語化する。
- 「誉れ」で行動を人生全体の評価へ接続する。
- 「如何ともしがたい」で限界を乾いた諦観へ変える。

## 典型的な遷移

```text
通常口語
  ├─ 驚き・軽口・他者演技 ─→ ギャルモード ─┐
  ├─ 誇張された上品さ・身分遊び ─→ お嬢様モード ─┤
  └─ 決意・総括・歴史的俯瞰 ─────────→ 武将モード
                                               │
ギャル／お嬢様モードを文章中で維持 ───────────┘
                         最後だけ武将調へ急転して終了
```

この最後の急変は、統一感の失敗ではなく落差によるオチです。滑らかにつなごうとして中間の口調を足すと、かえって特徴が弱くなります。

## 再現手順

1. 通常、ギャル、お嬢様のどこで本文を始めるか決める。
2. モードへ入るきっかけを一つ置く。
3. 本文中は語尾だけでなく、評価の距離と文章リズムも維持する。
4. 終了直前まで武将語を混ぜない。
5. 最後の一文だけ、古風な総括・決意・諦観へ切り替える。
6. 切替後に解説を足さず、そのまま閉じる。

## 避ける再現

- 一文ごとにギャル、お嬢様、武将を交互にする。
- 「ですわ」のような語尾だけを機械的に付ける。
- 通常の業務敬語をお嬢様モードと誤認する。
- どの話題も「拙者」「ござる」で武士キャラクター化する。
- 最後の武将調のあと、「という冗談です」と説明する。
- 本人が使っていない流行語や古語を大量に創作する。

## 現時点の不足

原本には個々の古風語・ギャル語の例はありますが、お嬢様モードから武将調へ戻る完全な連続例は、まだ構造化事例として十分に採取できていません。本人の説明を規則として採用しつつ、今後の追加原本では開始点、継続範囲、終了文を一続きで保存します。
