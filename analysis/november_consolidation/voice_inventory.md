# 言い回しの確認を、使う場面まで含めて整理する

2026-11-04に、それまでの本人回答を [口調辞書](../../data/owner_voice_dictionary.json) へ追記した。整理日であり、個々の発話日を推定し直したものではない。VD037〜VD054の18項目を加え、全54項目になった。原文の回答は本チャットから転記したもので、独立した会話エクスポートとの照合は未実施である。

## 近い意味でも、本人が選ぶ形は異なる

| 項目 | 確認できた形 | 機械的に置き換えない形・条件 |
| --- | --- | --- |
| VD037 | 筋は通ってるが、気に食わん。 | この文脈の「気に入らん」から本人が訂正 |
| VD039 | 屁理屈こねるな | 未確認の類似表現へ広げない |
| VD040 | 御託を並べる／御託を寄越すな／御託を抜かすな | 必要な説明を求める意味には使わない |
| VD041 | 能書きは要らない／説明して。 | 「能書きは要る」と肯定側へ展開しない |
| VD046 | してやったり／やったった | 後者の方が多い |
| VD048 | やらかした／しくじる／しくじり | しくじる・しくじりの方が多い |

「要る要らない」という最初の回答だけでは肯定・否定の両方を使用形にしてしまうが、本人は後から否定側だけと限定した。辞書ではこの補足を保持する。「御託は要らん」のように助手が補った語尾は、本人の個別確認を経た形としては加えない。

## 声、文字、相手、頻度を別々に持つ

「しめしめ」は書き言葉のみ。「僥倖」は声に出しても独り言に近い場面で、相手に伝える場合は「ラッキー」が多いと説明している。表記を「ラッキー☆」にするのは砕けてよい場合。こうした条件を落とすと、使うこと自体は合っていても場面に合わない口調になる。

「願ったり叶ったり」「渡りに船」「詰めが甘かった」「やっちまった」「不覚！」も使用を確認した。ただし肯定回答だけの語について、頻度や全相手への許容を補ってはいない。「迂闊」は積極的に使い、「迂闊！」単独でも言うという明示がある。

「理屈と膏薬はどこにでも付く」は助手が提示した語で、本人は初めて聞いたかもしれず使わないと答えた。面白いという評価を、本人の既存語彙・使用実績へ変えない。

## 小難しい言い方で、相手への当たりを和らげる

「ぬかったな？」は主に他人のしくじりに向ける。本人は、敢えて小難しい言い方をすることで和らげると説明し、相手が本気で落ち込んでいる場合にも使うと答えた。難しい語は、堅さや威圧のためだけに選ばれているわけではない。

ただし、この言い方で実際に相手が慰められたと実証したわけではない。また自分の失敗に「あまり言わない」は絶対不使用とは異なる。辞書はこの程度の差を残す。

## 語の由来や人格まで補いすぎない

「仁義に悖る」は会話でも使う。漢字を今回知ったことと、語として使えることは両立している。古風な語を知ることから読書家などの習得経路へ飛ばない。

「吝かではない」は前向きに応じる意図で使い、相手の受け取り方を見ることもある。本人は誤解を訂正せず、発言通り実行する方針を純粋戦略と説明した。これは [既存の分析](../copilot002_exploration/09_fixed_wording_and_attention.md) と同じ会話に基づく補完であり、独立した新しい使用事例として水増ししない。
