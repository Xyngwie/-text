# 第三段階：判断・価値観・口調の分析

現在の版は **v011（語彙・構文・レジスターモード版）** です。第十版の164場面・452本人発言、19仮説を保ったまま、原本中の本人単独発言1,721件を横断し、多用する語、構文、古風な表現を調べました。さらに、本人の説明に基づき、ギャル調・お嬢様調へ入った後は文中でその調子を維持し、末尾だけ武将調へ戻る切替を再現規則にしました。全567区間の第三段階はまだ完了していません。

今回の中心は [語彙・構文の反復](v011/lexicon_and_constructions.md) と [レジスターモード](v011/register_modes.md) です。全体像は [口調の再現モデル](v011/voice_model.md)、発信時の主張設計は [立場を選ぶ発信モデル](v011/publication_model.md) を参照してください。
