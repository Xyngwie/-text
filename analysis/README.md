本人補足：[建設的な議論について](constructive_discussion_clarification.md)。反論には完成した解決策までは求めず、解決へ向かうきっかけを示す、という基準です。v036の「対案」の読みをこの範囲に訂正します。

現在の版は **v037（引き受ける仕事と負担の探索版）** です。正式な164事例・452本人発言・19仮説を維持し、開発・読解・取引で誰が何を担うかを比較しました。
