# 第十八版からの変更（v018 → v019）

- 最初のRSS校正で、AIの「選択可能なら合理的」という判断が、本人の「作者の意図と使い続けて生まれる愛着」へ大きく修整された差分を分析しました。
- [選択可能性と、作品の抵抗](attachment_and_authorship.md)を追加し、道具の管理可能性と作品の固有性を分けました。
- 原本の未使用6場面から、意図的な不完全さ、改変への懸念、逆向きの変化、偶然メタ、残したい時間差、人間性を失う統合を探索しました。
- RSS生成では「設定変更できる＝良い」と短絡せず、作者性・固有性・慣れによる愛着を反対側の評価軸として必ず検討する規則を追加しました。

最初の校正は実績ログですが、一件だけで一般的価値観にはしません。正式な事例、仮説、根拠数は据え置きです。v001〜v018の内容も変更していません。
