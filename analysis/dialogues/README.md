# Issueで進める第三段階の対話資料

ここは第3段階の壁打ち記録。本人確認と正式版への採録は別に記録する。 [現行の運用方針](../current_rules.md)。

本人の2026年10月23日の指示により、問いの作成と本人の返答に基づく暫定分析をIssueで進めます。[操作・設定・根拠・保存の境界](../../docs/STAGE3_DIALOGUE_ACTION.md)を参照してください。

`D*/turn-*.json` はAIの仮説、出典、本人の原コメント、訂正、次の問いを保存する資料です。区切り済みでも `complete_unconfirmed` であり、仮説全体の本人承認を意味しません。正式な `analysis/vNNN` と生成プロンプトへは自動反映しません。
