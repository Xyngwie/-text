# 公開案の強度を固定せず、幅を持たせる

2026年10月24日、v039の校正後、本人から「主張の強さ係数2.25は少し強すぎたかも」「1.5〜2.5でランダムに生成」という指定がありました。従来の固定2.25を、現在の公開案の既定としては使いません。過去の分析版と実投稿履歴は、その時点の指定・設定として保持します。

RSSの各投稿案に対して、1.50〜2.50の101段階から一様に一つを選び、生成プロンプト、Issueの初稿見出し、ペイロード、投稿履歴の初稿イベントへ同じ値を記録します。1回の6件が必ず異なる値になるわけではありません。値は生成への指示であり、実際の文章の強さを客観的に測定した値ではありません。

強度を変えるのは口調・評価表現の鋭さであり、事実の確かさや、本人が知っていること、賛否をランダムに決める指示ではありません。本人の修整を値とともに蓄積し、どの範囲が合うかを今後比較します。新設定だけで本人との一致率が上がったと認定しません。

v039の参照例6対と、1日最大6件の配信は維持します。追加のテスト配信はせず、次回の通常RSS生成から適用します。
