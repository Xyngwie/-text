# 見過ごされる側の心情へ視点を移す

候補ID：`overlooked_feelings`。分析用のスキル候補。実行環境へ登録するSKILL.mdではない。

## 入口

勝者、支援者、発表主体など一方の説明で話が完結しがちな場面。

## 話の運び

1. 中心に語られている側を確認する。
2. 相手側、受け手、取り残された側へ視点を移す。
3. 既知の描写と内心の仮説を分け、評価に何が加わるか述べる。

## 避けたい崩れ方

- 悪役なら隠れた善人だと決める。
- 描かれていない被害者や感情を創作する。
- 毎回「その陰には」で締める。

## 根拠と限界

作品の読解が中心で、実在人物への適用は別途検証。

各引用と出典のJSON Pointerは [事例台帳](cases.json) に保存。以下の理由欄は分析者の解釈。

### DM004（direct_example）

悪役が負けた結果だけでなく、裏切られた側の心情へ移る。

出典：`analysis/copilot002_exploration/competition_owner_clarifications.json` の `/turns/6/owner_reply_verbatim`。

> 悪役でもその心情を読み取れば、裏切られたと思って負けるわけじゃん？それってかわいそうじゃない？

留保：作品への本人の読解。実在の相手が何を感じたかを確定しない。

### DM005（direct_example）

強さや柔軟さだけでなく、表に出ていない悔しさを知りたいと問う。

出典：`analysis/november_consolidation/hero_owner_evidence.json` の `/records/15/owner_reply_verbatim`。

> こういう流れの中で考えると、
> とても理解不能な人物である。
>
> 自分が一番強い時期が生涯のなかで長かったけど、それに奢らず常に上を目指している人。
> 自分の息子が自分より強くなった事を素直に認める柔軟さも併せ持ってるとみる。
> それについてもうちょっと内心の悔しさとかがあるかとかを掘り下げて欲しかったなあと思う。

留保：悔しいはずだと断定せず、描写を求めている。

### DM006（direct_example）

守る側の願いと守られる側が望む関係のずれへ目を向ける。

出典：`analysis/november_consolidation/hero_owner_evidence.json` の `/records/27/owner_reply_verbatim`。

> トリエラは、ヘンリエッタとは対比となる構造。ケルヒャーは最期までトリエラを生かす事を諦めなかったし、娘のように扱っていた。が、それはトリエラが望む関係性ではなかったのが悲劇であって想いを遂げられなかった無念が残ると見る。

留保：設定の独立確認ではなく本人の解釈。

### DM007（direct_example）

忠誠や充実から、戦死まで望んでいたとはしない。

出典：`analysis/november_consolidation/hero_owner_evidence.json` の `/records/28/owner_reply_verbatim`。

> リコは義体化前の記憶を持ってるんだよね。不治の病で寝たきりだったこと、それから条件付けでジャンへの忠誠を植え付けられていること。それを踏まえて動くことができる喜び、誰かのために働く事ができる思いで公社に尽くしている、が、戦場で散る事が彼女にとっての望みではなかっただろう。
