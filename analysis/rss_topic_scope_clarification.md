# 既知の興味に限定しない題材収集

2026年10月23日、本人から次の指示がありました。

> もっと僕の興味と無関係でもよく、あらゆる事柄について扱ってほしい。それについて僕なりの反応をすることで正しく僕が何を考えるかをモデル化することができると考える。

RSSの目的を、既存の関心に沿うニュースの推薦だけに限定しません。広い分野の題材への本人の反応を得て、既存の価値観の読みが別の題材でも成立するか、どこで変わるかを確かめるための指示です。

題材への知識不足、関心の薄さ、判断保留も、賛否や修整文とは違う反応として残します。すべての分野に本人の確立した見解があるとは認定しません。また、選んだニュース、AI初稿、本人の反応は分けて扱い、ニュースの頻度から本人の関心の強さを逆算しません。話題を広げるだけで人物モデルの正しさが保証されるわけでもありません。

この指示を受け、取得と選択を17分野の巡回へ拡張しました。正式な人物仮説やモデル追加学習の実施とは別です。
