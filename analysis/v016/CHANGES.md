# 第十五版からの変更（v015 → v016）

新しい会話事例や人物仮説は追加していません。既存の判断・価値観事例を横断し、複数の価値が衝突した時に判断が反転する条件を整理しました。

- 価値観を固定順位へせず、先に確認されやすい六つの条件として整理しました。
- 手続と期限、効率と学習、配慮と被害防止など七つの衝突を分析しました。
- 通常の選択が逆転する八つの境界を自然言語でまとめました。
- 新しい題材で立場を選ぶための六つの問いへ変換しました。
- 構造化した条件モデルを `decision_policy.json` に追加しました。
- E118の危険な期限優先を一般的な推奨規則にしない限界を明記しました。

v001〜v015の内容は変更していません。
