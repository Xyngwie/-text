# 第三版からの変更（v003 → v004）

第三版を凍結したまま、分析プールから25場面を追加しました。累計は108場面・288の本人発言です。今回は、感情の変化、自己訂正、説明・専門範囲の境界、使う時に区別できない仕組みへの反応を優先しました。

## 主な更新

| 項目 | 第四版で加えた条件 | 主な追加事例 |
|---|---|---|
| J01：責任と確認 | 書面と口頭、接触経過、専門外の線引きを追加。 | E92〜E95 |
| J02：効率以外の価値 | 観察条件、現在の身体能力に合う選択、将来基盤を追加。 | E88、E90、E106 |
| J03：説明の区切り | 表記規則は掘り下げ、専門外・際限のない依頼は止める対比を追加。 | E85、E92、E93、E103 |
| J05：問い直し | 理想の欠点を認める一方、名前から人物像を先取りする反例を追加。 | E85、E104、E108 |
| J06：使える表現 | 資金区分が見えないため方法自体を止める可能性と、判定フロー化を追加。 | E99、E105 |
| J07：強い表現の後 | 謝罪による肩透かしと、悲観から可能性へ揺れ戻す例を追加。 | E84、E86 |
| J09：価値の層 | ゲームの本質、物語、課金設計を別の価値として扱う例を追加。 | E87、E89 |
| J10：段階化 | 概念だけの転用、将来用の基盤、可視化不能なら停止という境界を追加。 | E99、E103、E105〜E107 |
| J11：予想との落差（新規） | 事前の予想と結果の差が感情と次の動きへ関わる仮説を追加。 | E84、E86、E91、E96 |

## 変えていないこと

- v001〜v003、原本、第二段階の分類、分析プールと再利用保留の割り当ては変更していません。
- 感情表現や身体症状は診断にせず、名前・性別・作中人物への推測は確認済み事実にしていません。
- 賭け方の停止線や回収設計を、数学的に有効な安全策とは評価していません。
- 既存ログは遡及的に読まれているため、保留分は未見検証ではありません。

第三段階は継続中です。次は、仮説間で同じ事例を参照しすぎていないかを整理し、未使用区間から独立性の高い反例を探します。
